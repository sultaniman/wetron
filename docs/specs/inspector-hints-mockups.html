Outlier by whose standard?

A finding named norm outlier with no stated rule is an assertion, not a diagnosis. The hint gives the actual test — median + 6 × MAD along the selected axis — and the numbers it resolved to, so you can judge whether the flag is interesting or just a tight distribution.

sparsity

11.77% zeros — but they aren't trained

This is the hint I'd most want as a researcher. On a Q4_0 tensor, a large share of exact zeros is an artifact of code 8 dequantizing to exactly zero, not evidence of learned sparsity. Reading 11.77% as prunable structure would be a real mistake, and no other part of the panel warns you.

What the mocks changed about the plan

  • Tooltips need multi-line support

    The kernel-layout hint is a four-row table, and it's the single most useful hint in the set. Both Tooltip components render plain text in a 280px box — they need white-space: pre-line and a wider max-width for hints. Small change, but it wasn't in the plan I showed you.

  • Two labels want rewording, not just a hint

    input per group → input ch, and saturation: 2 → 2 / 32. A hint that has to undo its own label is a hint doing the label's job.

  • Axis options carry their extent

    axis 0 → axis 0 · 288 across matrix, sparsity, per-axis and diagnostics. Cheap, and it removes a lookup from every axis decision.

  • The quantization histogram was mislabelled by placement

    It sits under a block control but plots tensor-wide code frequencies. That's a correctness problem in the UI, not a hint gap — it needs the scope stated on the chart.
